## Compliance Notes

This draft is written as an independent professional and academic website. It avoids institutional logos, avoids positioning the site as an official employer or hospital site, and includes:

- no patient intake form
- no request for protected health information
- no claim that the site represents an employer or health system
- referral navigation through the public Arkansas Children's Hospital Neurosciences and outpatient referral pages
- personal-views disclaimer noting that the website does not represent UAMS or any affiliated health system
- basic accessibility practices: semantic HTML, skip link, visible text contrast, responsive layout, alt text where meaningful

Before launch, review the content with the relevant communications/compliance team if the site will be interpreted as employer-affiliated.

## Free GitHub Pages Setup

1. Create a GitHub account or sign in.
2. Create a new public repository named `ayush-gupta-site` or `yourusername.github.io`.
3. Upload these files to the repository root, not inside a subfolder.
4. In GitHub, open `Settings` > `Pages`.
5. Under `Build and deployment`, choose `Deploy from a branch`.
6. Choose branch `main` and folder `/root`, then click `Save`.
7. GitHub will publish the site after a short build. The URL will look like:
   - `https://yourusername.github.io/ayush-gupta-site/`, or
   - `https://yourusername.github.io/` if the repository is named `yourusername.github.io`.
